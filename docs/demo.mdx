# Live Demo

Try FastGateway in a free hosted sandbox. No cluster, no install, no sign-up.

:::tip Open the sandbox

[demo.fastgateway.dev](https://demo.fastgateway.dev) &nbsp;·&nbsp; username `admin` &nbsp;·&nbsp; password `admin`

The sandbox resets every 30 minutes, so treat anything you create as throwaway.

:::

This walkthrough goes from an empty instance to a working domain and route. Follow the steps in order. It takes about ten minutes.

<Step number="1" title="Onboard a project (in-cluster)" src="/img/demo-1-project.jpg" alt="Create an in-cluster project">

A project is where FastGateway provisions your Gateway, domains, and routes. The demo uses the cluster FastGateway runs in.

1. Open Projects and click New Project.
2. Enter a name like `demo`.
3. Under Connection Type, pick In-Cluster (Local). Nothing else to configure.
4. Click Create Project.

</Step>

<Step number="2" title="Create a team and user" src="/img/demo-2-team-user.jpg" alt="Create a team and user" flip>

Teams own access to projects, and users belong to teams.

1. Open Teams and click Create Team. Name it `platform`.
2. Open Users and add a user with a username and password.
3. Add the user to the `platform` team.

</Step>

<Step number="3" title="Create a self-signed issuer" src="/img/demo-3-issuer.jpg" alt="Create a self-signed certificate issuer">

An issuer signs TLS certificates. A self-signed CA is enough for the demo.

1. Open Issuers and click New Issuer.
2. Keep the type Self-signed CA. Set a name like `selfsigned` and a common name like `demo-ca`, then click Create Issuer.
3. On the issuer page, under Grant Project Access, select `demo` and click Grant.

</Step>

<Step number="4" title="Onboard the team to the project" src="/img/demo-4-onboard-team.jpg" alt="Grant the team access to the project" flip>

A team has to be assigned to a project before it can use it.

1. Open the `demo` project and go to its Teams tab.
2. Click Assign Team and select `platform`.
3. Pick a permission preset like Editor, then click Assign Team.

</Step>

<Step number="5" title="Create a domain template" src="/img/demo-5-template.jpg" alt="Create a domain template">

A domain template holds the settings your domains share, so you set them once.

1. In the `demo` project, open Domain Templates and click Create Template.
2. Give it a name like `default`.
3. Pick a controller (Envoy Gateway), a service type (LoadBalancer), and a TLS mode (TLS Only).
4. Click Create Template.

</Step>

<Step number="6" title="Set up the TLS certificate" src="/img/demo-6-certificate.jpg" alt="The All Certificates page" flip>

FastGateway secures HTTPS with a Kubernetes TLS secret, signed by the issuer you granted in step 3. There is no file to upload.

1. Open All Certificates to see where issued certificates appear. It fills in as HTTPS domains come online.
2. Choose a secret name for your domain, like `demo-tls`. You reference it in the next step.

</Step>

<Step number="7" title="Create a domain" src="/img/demo-7-domain.jpg" alt="Create a domain">

A domain ties a hostname to a template and a TLS secret.

1. In the `demo` project, open Domains and click New Domain.
2. Choose the `default` template.
3. Enter a display name and a hostname like `demo.example.com`.
4. Set the TLS Secret Name to `demo-tls`.
5. Click Create Domain.

</Step>

<Step number="8" title="Create a route" src="/img/demo-8-route.jpg" alt="Create a route" flip>

A route forwards matching traffic on your domain to a backend.

1. Open your domain and click New Route.
2. On Basic Info, name the route `demo-route`.
3. On Traffic, keep Forward to Backend and add a backend service (namespace, service, port).
4. Click Create. The change goes through approval, then your domain serves traffic.

</Step>

## What you built

You now have a full path from request to backend: a project, a team, an issuer, a domain template, a TLS secret, a domain, and a route. The same flow works on a real cluster. See [Getting Started](/docs/getting-started/installation) to run FastGateway yourself, or [Concepts](/docs/concepts/projects) for how the pieces fit.
