# fastgateway.dev — open-source site + free GitHub Pages hosting

**Date:** 2026-10-03
**Status:** Implemented

## Goal

FastGateway is now fully open source. Reflect that on the website and move
hosting off the self-managed `docker-compose` + nginx stack onto **free GitHub
Pages**, with the source living in the new `fastgateway-dev/fastgateway.dev`
repository. Also close the SEO gaps (notably a missing `llms.txt`).

## Decisions

| Question | Decision |
|----------|----------|
| Content scope | Remove the hosted-console button **and** the entire pricing page |
| Hosting | GitHub Actions → GitHub Pages (not the `gh-pages` branch) |
| Source location | Migrate full source into `fastgateway-dev/fastgateway.dev`; deprecate the old `website` repo |
| llms.txt | Auto-generate with `docusaurus-plugin-llms` (not a hand-written static file) |
| Docker files | Remove — Pages replaces them |

## Changes

### 1. Content — remove console + pricing
- Remove the navbar **Console** link (`→ console.fastgateway.dev`) and its
  `.header-console-link` CSS.
- Keep the QuickStart "Access the Console" step — that is the **self-hosted**
  UI (`kubectl port-forward` → `localhost:3001`), legitimate for OSS.
- Delete `src/pages/pricing.tsx` + `pricing.module.css`.
- Remove the **Pricing** navbar item and the footer **Product** column (Pricing
  was its only link).

### 2. Hosting — GitHub Pages via Actions
- `.github/workflows/deploy.yml`: on push to `main` (+ `workflow_dispatch`),
  `npm ci` → `npm run build` → `upload-pages-artifact` → `deploy-pages`.
  Uses `fetch-depth: 0` so git history is available for `lastmod`.
- `static/CNAME` = `fastgateway.dev` (pins the custom domain on every deploy).
- `docusaurus.config.ts`: `organizationName` → `fastgateway-dev`,
  `projectName` → `fastgateway.dev`, `editUrl` → new repo. `url`/`baseUrl`
  were already correct (`https://fastgateway.dev` + `/`).
- Removed `Dockerfile`, `docker-compose*.yaml`, `nginx.conf`; trimmed the
  `Makefile` to npm-based targets.

### 3. SEO
- `sitemap.xml` already auto-generated by the classic preset — added `lastmod`.
- `robots.txt` already present and correct (kept as-is).
- `docusaurus-plugin-llms` generates `llms.txt` (index) + `llms-full.txt`
  (full text) at build, including blog posts.

## Manual steps (owner)
1. Push this repo to `github.com/fastgateway-dev/fastgateway.dev`.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. DNS for apex `fastgateway.dev` → GitHub Pages A records
   (`185.199.108/109/110/111.153`); set the custom domain in Pages settings and
   enable **Enforce HTTPS**.
4. Archive the old `fastgateway-dev/website` repo.
5. Tear down the `docker-compose` deployment once Pages is live.
