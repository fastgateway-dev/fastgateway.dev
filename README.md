This repository contains the **website** for FastGateway — the documentation, blog, and landing page published at **[fastgateway.dev](https://fastgateway.dev)**. Built with [Docusaurus](https://docusaurus.io/) and hosted free on GitHub Pages.

FastGateway itself is a web-based management interface for the Kubernetes Gateway API: create and manage Gateways, HTTPRoutes, and traffic policies through a UI and REST API instead of hand-writing manifests, with teams, approvals, and an audit trail on top.

## ✨ What's here

- **Documentation** — installation, concepts, task guides, and API reference (`docs/`)
- **Blog** — release notes and articles (`blog/`)
- **Landing page** — homepage and marketing sections (`src/`)

## 🚀 Local development

Requires Node.js >= 20.

```bash
npm ci      # install dependencies
npm start   # dev server with hot reload at http://localhost:3000
```

## 🏗️ Build

```bash
npm run build   # static output in ./build
npm run serve   # preview the production build locally
```

> Full-text search is generated at build time, so it only appears in `npm run serve`, not `npm start`.

## 🌐 Deployment

Hosted free on **GitHub Pages**. Every push to `main` triggers
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), which builds the
site and publishes it — no manual deploy step. The custom domain is pinned by
[`static/CNAME`](static/CNAME).

To serve on a fresh repository: enable **Settings → Pages → Source: GitHub
Actions**, then point the apex domain's DNS at the GitHub Pages A records
(`185.199.108.153`–`185.199.111.153`).

## 🔍 SEO
