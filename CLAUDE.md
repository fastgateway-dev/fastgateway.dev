## Project Overview

This is the **fastgateway.dev** website — the documentation, blog, and landing page for [FastGateway](https://github.com/fastgateway-dev), an open-source, UI-driven platform for managing Kubernetes Gateway API resources. Built with **Docusaurus 3.9.2**, React 19, and TypeScript.

## Commands

- `npm start` — Local dev server with hot reload
- `npm run build` — Production build to `/build`
- `npm run serve` — Serve production build locally
- `npm run typecheck` — TypeScript type checking (no tests exist)
- `npm run clear` — Clear Docusaurus cache

The same commands are wrapped in the `Makefile` (`make start`, `make build`, `make serve`, …).

## Deployment

Hosted **free on GitHub Pages** at `https://fastgateway.dev` via GitHub Actions.
`.github/workflows/deploy.yml` builds the site and deploys it to Pages on every
push to `main`. There is no manual deploy step — do not use `docusaurus deploy` /
the `gh-pages` branch. The custom domain is pinned by `static/CNAME`.

## Architecture

### Content Layer
- **`docs/`** — Markdown documentation organized by: Getting Started, Concepts, Tasks (Traffic Management, Security, Extensibility), Reference
- **`blog/`** — Blog posts in Markdown with `authors.yml` for author definitions
- **`sidebars.ts`** — Defines the docs sidebar navigation hierarchy

### UI Layer
- **`src/pages/index.tsx`** — Homepage composed of custom React components
- **`src/components/`** — Homepage sections: `HomepageHero`, `TrustBadges`, `HomepageFeatures`, `Architecture`, `Capabilities`, `QuickStart` (each with its own `index.tsx` + `styles.module.css`)
- **`src/css/custom.css`** — Global Docusaurus theme overrides (primary color: `#2563eb`)

### Configuration
- **`docusaurus.config.ts`** — Site config: navbar, footer, theme, code highlighting (bash, yaml, json supported via Prism), sitemap options, and the `docusaurus-plugin-llms` plugin
- URL `https://fastgateway.dev`, base URL `/` (custom-domain GitHub Pages — not a `*.github.io` subpath)

### SEO
- `sitemap.xml` is auto-generated by the classic preset's sitemap plugin (with `lastmod`)
- `static/robots.txt` allows all crawlers and points to the sitemap
- `llms.txt` + `llms-full.txt` are generated at build time by `docusaurus-plugin-llms`

## Key Conventions

- Homepage components follow the pattern: `src/components/<Name>/index.tsx` + `styles.module.css`
- Docs use Docusaurus front matter (`sidebar_position`, `title`, `description`) for ordering and metadata
- Blog posts use date-prefixed filenames (e.g., `2026-02-14-introducing-fastgateway/`)
- Node.js >=20.0 required
